# Good First Issues

## Add first-contact SLA timers by source
Add a configurable target first-contact time per source and flag routed leads whose received time is older than the target.

## Add address-line fuzzy matching as an optional signal
Let users opt in to a street-address similarity signal that can raise, but never create, a fuzzy cluster on its own.

## Add a credit status workflow
Let the ledger mark a credit as requested or received and export only the rows whose status changed.
